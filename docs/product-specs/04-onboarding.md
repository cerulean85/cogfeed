# Feature Spec: 온보딩 및 프로필 설정

> RICE Score: 850 | Priority: Must-have (P1, 최우선)
> PRD 참조: docs/target_prd.md 섹션 4, 9
> UX 참조: docs/ux_design_output.md 섹션 3 "회원가입 및 온보딩"

---

## 1. Goal

신규 사용자가 서비스에 쉽게 가입하고, 온보딩을 통해 핵심 기능을 이해한 뒤 첫 기록을 작성할 수 있다.

---

## 2. User Flow

```
홈 화면 → 회원가입 버튼 탭
  → 이용약관 동의 화면
  → 기본 정보 입력 화면 (이메일 + 비밀번호)
  → 회원가입 완료 화면
  → 온보딩 가이드 화면
  → 대시보드
```

**Alternative**: 소셜 로그인 (Google/GitHub 등) — TBD

---

## 3. Acceptance Criteria

- [ ] 이메일 중복 시 → "이미 사용 중인 이메일입니다." + 비밀번호 찾기 링크
- [ ] 필수 필드 미입력 시 → 필드 강조 + "모든 필드를 입력해 주세요."
- [ ] 온보딩 가이드: 핵심 기능 3–5단계 안내 (스킵 옵션 제공)
- [ ] 온보딩 완료 후 대시보드로 이동
- [ ] 비회원 탐색 옵션: "둘러보기" 버튼으로 일부 기능 체험

---

- 소셜 로그인 (Post-MVP 검토)
- 온보딩 튜토리얼 스와이프 (Post-MVP 권고)
