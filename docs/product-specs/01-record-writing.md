# Feature Spec: 기록 작성 기능

> RICE Score: 675 | Priority: Must-have (P1)
> PRD 참조: docs/target_prd.md 섹션 5
> UX 참조: docs/ux_design_output.md 섹션 3 "기록 작성 및 피드백 확인"

---

## 1. Goal

사용자가 자신의 생각·아이디어를 텍스트로 기록하고 저장할 수 있다.

---

## 2. User Story

- IT 개발자: "기술 학습 후 내 이해를 글로 정리하고 저장할 수 있다."
- 마케팅 전문가: "캠페인 분석 메모를 빠르게 입력하고 저장할 수 있다."
- 프리랜서 작가: "글의 초안을 작성하고 바로 피드백을 받을 수 있다."

---

## 3. Acceptance Criteria

- [ ] 기록 입력 필드: 최소 20자 이상 유도, 최대 500자
- [ ] 저장 버튼 탭 시 → 로딩 → 피드백 화면으로 이동
- [ ] 취소 버튼 탭 시 → 대시보드로 이동 (확인 다이얼로그)
- [ ] 저장 실패(네트워크 오류) 시 → "저장에 실패했습니다. 다시 시도해 주세요." + 재시도 버튼
- [ ] 필수 입력 미충족 시 → 필드 강조 + 오류 메시지

---

## 4. UI Components

| Component | Spec |
|-----------|------|
| 입력 필드 | ARIA label="기록 입력", textarea, 500자 제한, 키보드 접근 가능 |
| 저장 버튼 | ARIA label="저장", 최소 44×44px, 로딩 시 비활성화 |
| 취소 버튼 | ARIA label="취소", 최소 44×44px |
| 오류 메시지 | role="alert" |

---

## 5. Edge Cases

- 글자 수 0인 상태에서 저장 시도 → 저장 버튼 비활성화
- 500자 초과 입력 → 500자에서 cut-off, 토스트 경고
- 오프라인 상태에서 저장 시도 → 오프라인 안내 메시지

---

## 6. Out of Scope (MVP)

- 이미지/파일 첨부
- 음성 녹음
- 기록 분류/태그
